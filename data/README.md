
# Dataset Instructions

1. Download the credit-card fraud detection dataset from Kaggle:
   https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

2. Extract the downloaded archive if necessary.

3. Place the file named `creditcard.csv` directly inside this folder.

Expected path:

    data/creditcard.csv

The dataset should contain these columns:

- Time
- V1 through V28
- Amount
- Class

The target column is Class:
- 0 = non-fraud
- 1 = fraud

Do not upload the dataset to Git.
